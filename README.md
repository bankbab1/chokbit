# Bitcoin Key Lab
React + Vite + TypeScript + Tailwind CSS v4.

## Development
npm install
npm run dev

## Production
npm run build

## Behavior
- Cryptographically random valid secp256k1 private keys generated by @scure/btc-signer using Web Crypto.
- Compressed P2PKH, P2WPKH, P2SH-P2WPKH and BIP341-tweaked key-path P2TR addresses.
- Bitcoin mainnet and testnet.
- Browser-only key derivation. Keys are held only in memory, never logged, persisted, or sent to a server. Revealing allows deliberate copying to the system clipboard.
- Browser requests to Blockstream Esplora: confirmed balance, unconfirmed net change, transaction counts and paginated transaction history.
- Sequential address requests with 15-second timeout. Automatic mode waits 30/60/120 seconds after a completed key, pauses on errors or activity, and preserves the current key.
- Public API availability, CORS and rate limits determine lookup availability. Failure is displayed as unknown, never as a zero balance.
- Totals sum the four addresses; transaction counts can count the same transaction more than once.

## Important limitations
This experimental app is for education and testing, not custody of real funds. Random generation cannot practically discover existing funded wallets. Generic P2SH requires a redeem script; this app chooses nested single-key SegWit. Private keys are not HD seeds or BIP39 mnemonics. Auto generation replaces the previous key in memory, and refresh clears the session. Copying a key puts sensitive data on your clipboard.
